# Shift Calendar widget

A custom Android home-screen calendar widget (`com.shiftcal.widget`) plus a desktop control panel that sends settings to it.

```
android/   the widget app (Java, no Gradle; built with build.sh)
panel/     control-panel.html — open it in a web browser on your computer
```

## WA outback look (v3.1)

Five one-tap looks (Day, Dusk, Scrub, Salt lake, Pilbara night) built from the WA bush and outback palette: palettes `oday odusk oscrub osalt opilbara`, matching event colour sets plus `outback` (all 11 colours), four landscape header pictures (`scene`: grass, pinnacles, saltlake, mesas; vector drawables generated by `tools/scenes.py`, which also writes the SVGs the panel uses), retro title fonts (`tfont`, OFL fonts in `android/assets/fonts`, drawn as a bitmap because widget text can only use system fonts), and wall-calendar details: `wktint`, `satred`, `grid`/`gridw10`, `numpos`, `tyear`, `hh`, `scene_pos`, `scene_h`, `scene_op`, colour overrides `x_wkend x_grid x_out`. Themes live in `Look.java` and the panel's `THEMES`; the phone keeps an "Undo last theme".

## Hand-drawn look, shapes, comic colours (v3.2)

Hand-inked scene variants (`scene_ink`, `scene_*_ink.xml`: pastel colours, wobbly pen outlines, hatching and stipple, all from `tools/scenes.py`). Pen linework over the calendar (`ink`, `inkbox` grid|boxes, `inkw10`, `wobble`, `hatch` none|lines|cross, `stip`, `x_ink`), drawn by `ShiftWidget.inkLayer` as one alpha-only bitmap tinted with the ink colour; the panel draws the same thing on a canvas. Corner radii `r_bg r_tile r_ev r_mk` snap to the fixed shapes `res/drawable/rr_*.xml` (0, 2, 4, 6, 8, 12, 16, 24, 99 = pill). Pastel palettes `psea plilac psand pnight` and comic palettes `cjungle cwave cviolet cmauve cstair cice csea` (colours sampled from Ben's reference pictures), sets `pastel` and `comic`, and 8 more one-tap themes. The panel preview supports drag-to-resize (picture, header, week rows, widget size, corner radii), dragging the picture to the bottom, and scroll-to-resize on text.

## Event colours, hand-drawn controls and fonts (v3.3)

- **Colour any event from the preview:** click an event block or all-day bar in the control panel's preview and pick from the timed set, all-day set, comic or outback swatches. Choose whether the colour is for that one event (by exact title, `trules`), its code (edits `rules`), or the whole timed / all-day set.
- **All-day colour set** (`eset_ad`: `same`, `auto` = the timed set turned half way round, any set id, or `custom` with `x_set_ad`). It recolours all-day events without a code in every "Colour by" mode. Themes set it to `auto`. Codes (including end codes such as `– RAE`) and single-event colours still win; cancelled events stay grey.
- **Finer pen controls:** roughness (`rough` 1–3), hatch angle (`hang`), spacing (`hgap10`), which days (`hwhere`), dot amount and days (`stipd`, `stipon`), and a pen outline around events and all-day bars (`inkev`, on in the Ink and Comic themes).
- **No picture option** (`scene_off`, v3.3.1): hides the landscape picture so the calendar gets the room; picking a look does not turn it back on.
- **Fonts for each kind of text:** title (`tfont`, `tls` spacing), weekday names (`f_dow`, `dowbold`, `dowls`), dates (`f_num`, `nbold`, `nls`), event text (`font`, `evsx` width) and all-day text (`f_mk`). Phone font families draw as normal text. The retro and hand-lettered fonts (8 new: Comic Neue, Gloria Hallelujah, Architects Daughter, Caveat, Indie Flower, Gochi Hand, Shadows Into Light, Permanent Marker; OFL, Permanent Marker Apache 2.0) are drawn as pictures for the title, weekday names and dates.

## Using the control panel

1. Install the latest `ShiftCalendar.apk` on the phone (v3.0 or later).
2. On the computer, open `panel/control-panel.html` in Chrome, Edge or Firefox (double-click it). Open it from your disk; a hosted copy can't reach the phone.
3. On the phone: Shift Calendar → **Receive settings from computer**. It shows an address (like `192.168.1.23:8765`) and a 4-digit pairing code.
4. Type both into the top of the panel and press **Load from phone**. The preview now shows your real calendar.
5. Change anything; the preview updates as you go. Press **Send ➤** and the widget redraws.

The phone only listens while the Receive screen is open, only on your Wi-Fi, and only answers requests with the current pairing code (a new one each time the screen opens).

**If Send can't reach the phone** (some routers block device-to-device traffic, guest networks always do): in the panel's *Save & share* tab press **Copy settings code**, get that text to the phone (email/message it to yourself), and paste it into the Receive screen.

## What the panel controls

View (rolling/month, weeks, past strip, row heights, custom taper), timed events (placement, clock, time window, lines, detail, overnight), event text (bold time, hours style, location, capitals, start-code colour/bold), all-day markers, filters and calendars, font family, every text size, line spacing, today outline, colour bar width, current-time line, header buttons, palette plus an override for each individual colour, see-through levels, event colour mode, colour sets (or your own list), code colours, time zone, and a raw JSON editor for everything. Designs can be saved to / opened from `.json` files.

## Building the app

Needs Ubuntu packages `aapt apksigner zipalign dalvik-exchange`, a JDK, and `android.jar` (android-33) from github.com/Sable/android-platforms at `/home/user/sdk/android.jar` (or set `ANDROID_JAR`).

```
cp /path/to/release.keystore android/      # never committed (.gitignore)
KS_PASS=… sh android/build.sh               # -> android/bin/ShiftCalendar.apk
```

Updates must be signed with the same `release.keystore`, or Android refuses to install over the existing app. Bump `versionCode`/`versionName` in `android/AndroidManifest.xml` for each release.

### Settings protocol (v3.0)

`ReceiveActivity` runs a tiny HTTP server on port 8765 (next free port up to 8774). All requests need `?pin=NNNN`.

| Request | Does |
|---|---|
| `GET /ping` | `{ok, app, version}` |
| `GET /state` | settings, calendars, and events from 21 days back to 84 days ahead (for the preview) |
| `POST /apply` | body `{"settings": {...}}`; numbers → int prefs, strings → string prefs, arrays → string sets, `null` → remove (use phone default) |

Settings codes are `SC1` + base64url(raw-deflate(JSON)). `shiftcal://import?d=<code>` also opens the Receive screen and asks before applying.
